# Boris Cherny Job Archetypes Framework

Below is the structured mapping of the 5 product archetypes used to categorize tasks and milestones during the autonomous macro agent swarm build-out.

| Icon | Archetype | Core Definition | Swarm Lifecycle Equivalents |
| :---: | :--- | :--- | :--- |
| <img src="icons/prototyper.png" width="32" height="32" alt="Prototyper"> | **1. The Prototyper** | Churns out brand-new ideas and concepts, the vast majority of which are never meant to be shipped to production. | • Prompting a standalone LLM to draft initial code definitions.<br>• Testing quick API hooks to see if publisher data feeds parse correctly. |
| <img src="icons/builder.png" width="32" height="32" alt="Builder"> | **2. The Builder** | Rapidly transforms a raw concept or rough prototype into a production-grade, highly available product and infrastructure. | • Constructing the multi-agent system on Hyperagent.<br>• Linking trigger events to real-time execution pipelines. |
| <img src="icons/sweeper.png" width="32" height="32" alt="Sweeper"> | **3. The Sweeper** | Focuses on subtraction and refinement—cleaning the system, simplifying bloat, unshipping bad code, and optimizing performance. | • Refining the contextual tokens passed to the agent swarm.<br>• Refactoring business rules to minimize loop latency and context costs. |
| <img src="icons/grower.png" width="32" height="32" alt="Grower"> | **4. The Grower** | Takes the functional, built architecture and iterates continuously on it to refine its Product-Market Fit (PMF). | • Adjusting how the swarm formats its real-time market insights.<br>• Tailoring final reports to ensure actionable value for your blog or dashboard. |
| <img src="icons/maintainer.png" width="32" height="32" alt="Maintainer"> | **5. The Maintainer** | Owns the mature system, ensuring it remains highly secure, efficient, reliable, and fast as it scales under load. | • Hardening the platform integrations against publisher layout changes.<br>• Managing API keys, rate limits, and structural uptime. |
