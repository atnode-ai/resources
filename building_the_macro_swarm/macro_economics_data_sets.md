# Macroeconomic Data Sets Quick Reference Guide

Below is a structured quick reference layout mapping out the 12 independent data sets detailed within the complete guide.

| Category | Economic Data Set / Release | Primary Impact Level | Key Metrics Tracked |
| :--- | :--- | :--- | :--- |
| **Inflation Data** | Consumer Price Index (CPI) | Red Folder (High) | Headline & Core MoM/YoY |
| | Personal Consumption Expenditures (PCE) | Red Folder (High) | Core PCE Deflator (Fed's 2% Target) |
| | Producer Price Index (PPI) | Orange Folder (Medium-High) | Wholesale Input Costs (Leading CPI Indicator) |
| **Labor Market Data** | Non-Farm Payrolls (NFP) | Red Folder (High) | Net Jobs Added, Unemployment Rate, Wages |
| | Job Openings & Labor Turnover (JOLTS) | Orange Folder (Medium) | Job Openings, Quits Rate, Layoffs |
| | Unemployment Claims | Orange Folder (Medium) | Weekly Initial & Continuing Claims |
| **Growth & Activity** | Gross Domestic Product (GDP) | Red Folder (High) | Quarterly Growth Rates, Deflator |
| | Retail Sales | Red Folder (High) | Core Control Group, Consumer Demand |
| | ISM Manufacturing PMI | Red Folder (High) | New Orders, Employment, Prices Paid |
| | ISM Services PMI | Red Folder (High) | Service Sector Activity, Prices Paid |
| **Monetary & Housing**| FOMC Rate Decision & Minutes | Red Folder (High) | Interest Rate Target, Dot Plot, Policy Guidance |
| | Building Permits & Housing Starts | Orange Folder (Medium) | Housing Supply Pipelines (Leading Growth Indicator) |
