# Macroeconomic Data Sets & Publishers Quick Reference Guide

Below is the expanded quick reference mapping out the 12 independent data sets alongside their respective official publishers.

| Category | Economic Data Set / Release | Primary Impact Level | Official Publisher | Key Metrics Tracked |
| :--- | :--- | :--- | :--- | :--- |
| **Inflation Data** | Consumer Price Index (CPI) | Red Folder (High) | Bureau of Labor Statistics (BLS) | Headline & Core MoM/YoY |
| | Personal Consumption Expenditures (PCE) | Red Folder (High) | Bureau of Economic Analysis (BEA) | Core PCE Deflator (Fed's 2% Target) |
| | Producer Price Index (PPI) | Orange Folder (Medium-High) | Bureau of Labor Statistics (BLS) | Wholesale Input Costs (Leading CPI) |
| **Labor Market Data** | Non-Farm Payrolls (NFP) | Red Folder (High) | Bureau of Labor Statistics (BLS) | Net Jobs Added, Unemployment Rate, Wages |
| | Job Openings & Labor Turnover (JOLTS) | Orange Folder (Medium) | Bureau of Labor Statistics (BLS) | Job Openings, Quits Rate, Layoffs |
| | Unemployment Claims | Orange Folder (Medium) | Department of Labor (DOL) | Weekly Initial & Continuing Claims |
| **Growth & Activity** | Gross Domestic Product (GDP) | Red Folder (High) | Bureau of Economic Analysis (BEA) | Quarterly Growth Rates, Deflator |
| | Retail Sales | Red Folder (High) | US Census Bureau | Core Control Group, Consumer Demand |
| | ISM Manufacturing PMI | Red Folder (High) | Institute for Supply Management (ISM) | New Orders, Employment, Prices Paid |
| | ISM Services PMI | Red Folder (High) | Institute for Supply Management (ISM) | Service Sector Activity, Prices Paid |
| **Monetary & Housing**| FOMC Rate Decision & Minutes | Red Folder (High) | Federal Reserve System | Interest Rate Target, Dot Plot, Policy Guidance |
| | Building Permits & Housing Starts | Orange Folder (Medium) | US Census Bureau / HUD | Housing Supply Pipelines (Leading Growth) |

### Publisher Summary Count
* **Bureau of Labor Statistics (BLS):** 4 data sets

* **Institute for Supply Management (ISM):** 2 data sets
* **US Census Bureau:** 2 data sets
